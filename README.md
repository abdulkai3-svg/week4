## Weather Reporter

For this project, I made a Python program that shows the weather for a city. It shows the temperature, humidity, and weather description. It also saves the information in a CSV file.

## How to Run

Install requests using python3 -m pip install requests, then run python3 reporter.py.

You will need a free API key from OpenWeatherMap. You can sign up on their website and find your key under API Keys. Keep your key private and don't upload it to GitHub.

Once the program runs, enter a city name and your API key.

## Files

reporter.py: Main code

city_data.csv: Saved weather information
